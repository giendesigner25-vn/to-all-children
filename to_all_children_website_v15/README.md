# TO ALL CHILDREN — V12

V12 adds a Parent Portal with registration/login, favorites, reading progress and a bilingual story library.

## Run
1. Install Node.js 20+.
2. Run `npm install`.
3. Run `npm start`.
4. Open `/portal.html` for the Parent Portal and `/` for the Admin Dashboard.

Passwords are stored as salted scrypt hashes. Parent sessions are held in memory for this development version.
